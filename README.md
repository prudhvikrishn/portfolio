# Prudhvi Krishna — Portfolio

Personal portfolio of Dupakuntla Prudhvi Krishna, B.Sc. Data Science student at VIT-AP University.

Live: https://prudhvikrishn.github.io/portfolio/

Built with React, Vite, framer-motion and three.js.

## Run locally

```
npm install
npm run dev
```

Pushing to `main` builds and deploys the site to GitHub Pages (see `.github/workflows/deploy.yml`).
